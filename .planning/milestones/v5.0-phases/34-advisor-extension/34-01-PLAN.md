<objective>
Add a new `inference` diagnostics-only advisor aspect (ADV-03) that summarizes an fdars-computed `TestResult` dict (`{statistic, p_value, n_perm}`, and tolerating the SCB `ToleranceBand` dict shape `{lower, upper, center, half_width}` where relevant) produced by the Phase 31 `fdars.inference` functions. The builder derives significance flags at alpha = 0.01 / 0.05 / 0.10 (each `p_value < alpha`) — trivially derived from the fdars-computed p_value, never fabricated. This is the 14th aspect (12 in v3.0 + `scoring` #13 in v4.0 + `inference` #14).

Purpose: Extend the grounded advisor so a user can interpret a functional-inference result through the same interpret/recommend/method-guidance surface as every other aspect, with the grounding invariant intact (fdars computes every number; the builder only summarizes; the LLM only interprets and cites).

Output: New `aspects/inference.py` builder; `"inference"` registered in advisor `_supported` + dispatch, MCP `_DIAGNOSTICS_METHODS`, and `_ASPECT_PRIMERS`; an offline test suite. Pure-Python phase — no maturin rebuild needed; run pytest.
