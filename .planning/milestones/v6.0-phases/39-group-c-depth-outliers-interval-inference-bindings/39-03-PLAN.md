<objective>
Expose fdars-core 0.23.0's three interval-wise testing procedures (ITP) — `itp_one_pop`, `itp_two_pop`, `itp_flm` — through `fdars.inference` by extending `src/inference_mod.rs` (per D — CONTEXT.md locked decisions ITP-01..04). Each returns an `ItpResult` whose p-values are VECTORS (one per projection-basis coefficient), so a NEW `itp_result_to_pydict` helper is required — distinct from the scalar-oriented `test_result_to_pydict` — exposing `adjusted_pvalues`/`raw_pvalues` as 1-D numpy arrays. `basis_type` string-dispatches a `#[non_exhaustive]` `ProjectionBasisType` (bspline/fourier) with a `ValueError` wildcard; `seed=None` resolves to the fixed default `0` for byte-identical permutation reproducibility (same pattern as `t_perm_test`).

The first task is a tracer that wires ONE test (`itp_one_pop`) end-to-end (kwargs → FdMatrix + optional mu0 slice + `basis_type_from_str` → core `itp_one_pop(...)` → `#[non_exhaustive]` `ItpResult` field-by-field → dict with 1-D p-value arrays + basis_type string + int fields → registered + importable) BEFORE expanding to `itp_two_pop` (two-sample, seeded determinism) and `itp_flm` (re-fits internally from raw data/response). Purpose: deliver ITP-01 (itp_one_pop), ITP-02 (itp_two_pop), ITP-03 (itp_flm with ProjectionBasisType dispatch + internal re-fit), ITP-04 (registration via the new converter + vector p-values as 1-D arrays + degenerate ValueError).
Output: an extended `src/inference_mod.rs` (3 new `#[pyfunction]`s + `itp_result_to_pydict` + `basis_type_from_str` + `basis_type_variant_str` + 3 lines in `register()`) and extended `tests/test_inference.py` (`TestItpOnePop`, `TestItpTwoPop`, `TestItpFlm`).
</objective>
