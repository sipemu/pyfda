FRAMING / NARRATIVE (RESEARCH 3.1, 3.4): the page classifies phonemes by their spectral shapes — log-periodograms as functional data, shapelet discovery as interpretable feature extraction (subsequences that maximally separate classes by information gain). Main example uses 3 acoustically-distinct classes (aa=vowel, sh=fricative, dcl=stop), 30 curves/class, achieving ~72-78% test accuracy. Follow the arc: intro → data (show the 3 class spectra) → discovery (summary dict; explain what shapelets are) → feature extraction (feature-matrix heatmap by class) → classification (kNN; train + per-class test accuracy) → honest accuracy framing + a "scaling up to 5 classes" note → interpretation → Parameters + See also.

DATA CONSTRUCTION (RESEARCH 3.3 — VERIFIED): `freq, X, meta = load_phoneme()` → X (400, 256), meta['phoneme']. `ph = meta["phoneme"].to_numpy()`. 3-class subset `c_sel = ["aa","sh","dcl"]`, `n_per = 30`: `idx = np.concatenate([np.where(ph == c)[0][:n_per] for c in c_sel])`; `X_sub = np.ascontiguousarray(X[idx], dtype=np.float64)` (contiguity REQUIRED — RESEARCH pitfall 8, else a buffer error); `y_sub = np.array([i for i in range(3) for _ in range(n_per)], dtype=np.int64)`. 80/20 split per class: `tr_idx = np.concatenate([np.where(y_sub==i)[0][:24] for i in range(3)])`, `te_idx = np.concatenate([np.where(y_sub==i)[0][24:] for i in range(3)])`.

EXACT API CALLS (RESEARCH 3.3 key API facts — all VERIFIED against src/shapelet_mod.rs; honor gotchas):
- `disc = discover_shapelets(X_tr, y_tr, max_candidates=200, seed=42)` — returns a SUMMARY DICT `{'n_shapelets': int, 'quality': str}`, NOT a list of shapelet arrays. Access `disc["n_shapelets"]` / `disc["quality"]`. Do NOT iterate `disc` as if it were a list of subsequences (RESEARCH pitfall 4).
- `stfit = shapelet_transform_fit(X_tr, y_tr, max_candidates=200, seed=42)` — returns a PyShapeletFit handle with `.n_shapelets` and `.n_train`. `feat_tr = shapelet_transform(stfit, X_tr)` → (72, K); `feat_te = shapelet_transform(stfit, X_te)` → (18, K), K = stfit.n_shapelets.
- `clf = shapelet_classifier_fit(X_tr, y_tr, max_candidates=200, seed=42, classifier="knn", k=1)` — returns a PyShapeletClassifierFit handle with `.train_accuracy`, `.n_shapelets`, `.classes`, `.n_classes`. `preds = clf.predict(X_te)` → (18,) int64. `test_acc = np.mean(preds == y_te)`. Per-class: `[np.mean(preds[y_te==i] == y_te[y_te==i]) for i in range(3)]`.
- `max_candidates=200` caps the candidate search — REQUIRED to keep the fence to ~2s (RESEARCH 3.5). `classifier` is `"knn"` or `"lda"` only; default `k=1`. Optionally mention LDA achieves higher test accuracy (~0.778) as a comparison.
- Frame accuracy HONESTLY: with only 30 curves/class and 256 grid points, shapelet discovery finds ~90 subsequences that partially separate the classes; report the measured test accuracy from the fence rather than a fixed claim.
