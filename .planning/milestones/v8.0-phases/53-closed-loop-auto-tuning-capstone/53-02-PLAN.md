<objective>
LLM proposal path: expose auto_tune() as the Python API that drives the wave-1 loop core with an LLM-backed propose_fn. The LLM proposes ONLY through a schema-validated numeric TuneProposal (Recommendation.parameter_delta); the orchestrator clamps it to the declared range; the clamped value is the single number from the LLM that ever enters the numeric path. Add the 'parameter_proposal' task clause to the system prompt with an explicit no-numeric-prediction prohibition (per D: TUNE-03).

Purpose: This is the grounding-invariant hard boundary for the tuning capstone — the LLM must never set a number directly in the numeric path, never be parsed from prose, and never be retried into the numeric path on a bad proposal.
Output: auto_tune() in advisor/__init__.py (exported), the 'parameter_proposal' clause in _prompts.py, and an offline test suite that injects a fake Provider to prove clamping, parse-failure-no-retry, and the qualitative-only constraint.
</objective>
