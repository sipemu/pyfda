## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Python caller → PyO3 wrapper | Untrusted numpy arrays and scalar params (alpha) cross into Rust. |
| PyO3 wrapper → fdars-core | Marshalled FdMatrix crosses into the compute engine; a usize index crosses back and must be resolved to a curve. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-26-04 | Tampering | functional_covariance m×m return | high | mitigate | Route through `convert::fdmatrix_to_numpy2d`; guard with diagonal==variance AND a known off-diagonal value (Pitfall 1 / #33 — symmetry alone is insufficient). |
| T-26-05 | Information Disclosure | depth_based_median return | medium | mitigate | Resolve the upstream `usize` to the actual curve row before returning; test asserts a length-m array equal to an observed row, never a bare int (Pitfall 4). |
| T-26-06 | Denial of Service | fallible core calls (n<2 variance/cov, α outside [0,1)) | medium | mitigate | Wrap every `Result` with `to_pyresult()`; NO `.unwrap()`; add `pytest.raises(ValueError)` degenerate-input tests. |
| T-26-SC | Tampering | npm/pip/cargo installs | low | accept | No new package installs — `fdars-core 0.17.0` already pinned/audited in Phase 25; this plan adds only bindings. |
