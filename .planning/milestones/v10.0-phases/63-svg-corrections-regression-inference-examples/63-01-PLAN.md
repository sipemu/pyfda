<accessibility_pattern>
Apply this A11Y pattern to EVERY one of the 40 SVGs (this is the universal A11Y-01 + A11Y-02 work).

**A11Y-02 — long-form title + desc wired via aria-labelledby.** Immediately after the `<svg …>`
opening tag (and its `<style>` block), add a `<title>` and a `<desc>` with unique ids, and
reference both from the root `<svg>` via `aria-labelledby`:

- `<title id="{slug}-title">` = the diagram's exact `.ttl` title text.
- `<desc id="{slug}-desc">` = 1–2 sentences describing WHAT the diagram depicts AND the
  method/workflow it illustrates (method-accurate; grounded in the diagram content and, for
  examples, the matching docs example page). Wording is the executor's discretion.
- Root `<svg>` gains `aria-labelledby="{slug}-title {slug}-desc"` (space-separated, title first).
- Use a stable, file-derived `{slug}` for ids (e.g. the filename stem) so ids are unique
  per-document and svgo-safe.

**A11Y-01 — aria-label matches title verbatim.** The root `aria-label` currently paraphrases the
title on every diagram in this bucket. Set the root `aria-label` to the EXACT visible `.ttl`
title text (decode HTML entities to the visible glyph, e.g. `&amp;` renders as `&`, `&#8594;`
renders as `→`, so the aria-label uses the visible character). Where the `.ttl` element spans
the title only (subtitle is a separate `.sub` element), match the `.ttl` text only.

Keep `role="img"` on the root `<svg>` (already present on all 40). `aria-labelledby` +
`aria-label` may coexist; `aria-labelledby` takes precedence for AT, and the verbatim
`aria-label` satisfies the A11Y-01 grep/title-match check.
</accessibility_pattern>
