  <action>
Create a self-contained, dependency-light Python script that proves the base
package works with ZERO provider extras installed (QUAL-04). The script is the
end-to-end tracer for the packaging surface: it is the SAME assertion CI's
bare-venv job runs and that a developer runs locally.

The script must, in order, and exit non-zero on the first failure with a clear
message:
  1. import fdars — assert it succeeds.
  2. from fdars import advisor — assert it succeeds (advisor package importable
     with no provider SDK present).
  3. Build a deterministic offline diagnostics dict via
     advisor.build_diagnostics on the "represent" aspect using a fixed
     numpy.ones((20, 50)) data matrix and numpy.linspace(0, 1, 50) argvals
     (the represent branch accepts a raw {"data", "argvals"} dict directly — no
     fdars method output needed, no provider dep, fully offline). Assert the
     returned value is a dict and that json.dumps(result, sort_keys=True)
     serialises without error (proves JSON-serialisable, no numpy scalars).
  4. Assert that requesting a provider whose extra is NOT installed raises an
     actionable ImportError: call advisor.advise(diagnostics, task="interpretation",
     domain_context="smoke", provider="openai") inside a try/except and assert an
     ImportError is raised whose message names the pip install extra. Use the
     provider name for whichever extra is guaranteed absent in a bare venv; since
     the bare venv installs NO extras, "anthropic" (the default provider) also
     raises ImportError, so a provider=None call is an equally valid assertion —
     pick one and assert the raised ImportError message contains "pip install
     fdars[". Do NOT hardcode the exact bracket contents beyond the "pip install
     fdars[" prefix so the assertion stays adapter-agnostic.

Structure the script with a main() returning an int exit code and a
`if __name__ == "__main__": sys.exit(main())` guard so CI can gate on the exit
status. Print a one-line PASS summary on success. Import numpy and json at module
top; do NOT import anthropic/openai/gemini/ollama/mcp anywhere in the script.
Keep it under ~60 lines. This is production tooling, not a throwaway — it ships
under scripts/ and is the canonical bare-venv proof.
  </action>
