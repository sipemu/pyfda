<objective>
Add two new PyO3 bindings to the EXISTING `fdars.regression` submodule (`src/regression_mod.rs`), exposing fdars-core 0.23's `concurrent_regression` (varying-coefficient functional regression) and `functional_glm` (exponential-family GLM over FPC scores), layout-correct across the numpy↔FdMatrix boundary, with new `tests/test_regression.py` coverage.

The first task is an end-to-end tracer that proves the single highest-risk architectural question — whether a Python `list[np.ndarray]` binds to `Vec<PyReadonlyArray2<'py, f64>>` (RESEARCH flags this LOW-confidence, A2) — by wiring `concurrent_regression` through per-element conversion → core call → `to_pyresult()` → PyDict → registration → importable Python smoke, before expanding to full field/family/guard coverage.

Purpose: Deliver the two regression estimators (REGR-01, REGR-02) with the `(p, m)` `beta_curve` transposition proven, all 4 GLM families dispatching, the embedded fpca kept internal, and every degenerate input raising `ValueError` (REGR-03) — proving the list-binding architecture on one path first so a binding dead-end surfaces after one commit, not four.
Output: New `#[pyfunction]`s + two `*_to_pydict` converters + `family_from_str` helper + `register()` edits in `src/regression_mod.rs`, and a new `tests/test_regression.py`.
</objective>
