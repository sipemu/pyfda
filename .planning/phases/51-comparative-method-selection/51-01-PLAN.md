<objective>
Deliver the deterministic ranking core for comparative method-selection: a new
`compare_methods()` entry point whose offline path (`run_llm=False`) runs
`build_diagnostics` over N labeled candidates and returns an **fdars-computed**
ranking on a shared metric. This is the phase TRACER — one path (candidate specs
and pre-computed dicts → guard → metric registry → deterministic sort → winner)
wired end-to-end and proven reproducible BEFORE any LLM narration (Plan 02) or
MCP tool (Plan 03) is built.

Purpose: The single most important correctness property of Phase 51 is that the
winner comes from a deterministic fdars sort, not the LLM (COMPARE-01), and that
incommensurable comparisons fail closed (COMPARE-03). Proving this end-to-end on
the executor's best early-context tokens catches any architectural dead-end after
one commit.

Output: `python/fdars/advisor/_compare_methods.py`, `compare_methods` exported
from `fdars.advisor`, offline determinism + guard tests.
</objective>
