<objective>
Build the capability-discovery TRACER: a generator script that introspects the live
`fdars` public surface and emits ONE canonical `python/fdars/_capability_map.json`, plus
the SKILL-02 accuracy test that proves the map never drifts from the live package and every
mapped callable is importable. This map is the single source of truth that the skill (78-02),
docs/llms.txt (78-03), and the MCP tool (78-04) all consume — so proving introspect → stable
JSON → accuracy-green FIRST catches an architectural dead-end after one commit.

Purpose: Make the three downstream surfaces impossible to drift apart (all fed from one JSON)
and make SKILL-02 trivial (regenerate → assert no diff + everything importable).
Output: the generator, the committed capability map, a curated-guidance data file, and the
SKILL-02 test.
</objective>
