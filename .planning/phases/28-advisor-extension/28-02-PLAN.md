<objective>
ADV-02: extend the two EXISTING advisor aspects with grounded quality diagnostics for the new
v4.0 capabilities — imputation-quality on `represent`, registration-quality on `alignment` —
building on the wiring pattern proven by the 28-01 scoring tracer.

Per the LOCKED decisions (28-CONTEXT.md), these are EXTENSIONS of aspects already in
`_supported`/`_DIAGNOSTICS_METHODS`, so there is NO guard-sync churn here — only 28-01 (scoring)
touched the guarded sets. Every new diagnostic value is computed by a bound fdars function and
cites a real number (grounding invariant); nothing is Python arithmetic presented as a metric.

Purpose: give the grounded advisor coverage of imputation quality and registration quality so
`advise()` can interpret them with method-accuracy.
Output: extended `represent`/`alignment` builders + primer updates + offline determinism and
grounding tests.

LOCKED decisions honored:
- Imputation-quality → extend `aspects/represent.py` (represent operates on INPUT data);
  registration-quality → extend `aspects/alignment.py`. Neither changes `_supported` /
  `_DIAGNOSTICS_METHODS`.
- Registration-quality summarizes the 3 fdars quality scores `least_squares_score`,
  `pairwise_correlation_score`, `sobolev_least_squares_score`.
- Imputation-quality: fraction of points imputed (structural count) + a residual/consistency
  measure computed via a bound fdars function — NOT Python math for the cited evidence value.
- Builders return JSON-serialisable dicts with plain floats/ints/strings — NO numpy scalars.
</objective>
