FRAMING / NARRATIVE (RESEARCH 2.1, 2.5): the page answers "how does the shape of a Canadian weather station's temperature distribution change with latitude?" — a genuine Fréchet-regression-in-density-space question. Warmer southern stations have right-shifted, narrower distributions; colder northern stations left-shifted, broader. Follow the 8-beat arc: intro → data + KDE densities (html figure) → why Fréchet (Euclidean mean of densities is not a valid density; Fréchet minimizes Wasserstein-2) → global regression (html figure of predicted densities by latitude) → local regression (bandwidth=5°) → ISE evaluation on held-out stations → interpretation (the prediction is itself a valid density integrating to 1) → Parameters + See also.

DATA CONSTRUCTION (RESEARCH 2.2, 2.3 — VERIFIED): load `load_canadian_weather("temperature")` → (35, 365) X, meta with `lat`. Build a common temperature grid `t_grid = np.linspace(X.min() - 2, X.max() + 2, 60)`. For each of the 35 stations, `gaussian_kde(X[i], bw_method="silverman")(t_grid)`, clip to non-negative (`np.clip(..., 0, None)` — RESEARCH pitfall 7), then `normalize_density(..., t_grid)` from `fdars.density_fda` so each row integrates to 1. Stack into `density_matrix` shape (35, 60). Predictor `lat = meta["lat"].to_numpy()` shape (35,).

EXACT API CALLS (RESEARCH 2.4 — all VERIFIED against src/frechet_mod.rs / fdars.density_fda; honor every gotcha):
- Density mean for the intro/motivation: use `wasserstein_barycenter(density_matrix, t_grid)` from `fdars.density_fda`. Do NOT call `frechet_mean(..., space="density")` — that space is NOT supported by the binding (supports "spd"/"spherical"/"correlation" only); it raises ValueError. (RESEARCH pitfall 3.)
- Train/test split with `np.random.default_rng(42)`: 28 train / 7 test station indices.
- `frechet_global_reg(pred_train, resp_train, t_grid, pred_test)` where pred_train/pred_test are latitude columns reshaped `lat[idx].reshape(-1, 1)` (2D — passing 1D raises a shape error, RESEARCH pitfall 2). Returns dict with `predicted` (7, 60), `xout`, `x_bar`.
- `frechet_local_reg(pred_train, resp_train, t_grid, pred_test, bandwidth=5.0)` — returns dict with `predicted` (7, 60), `xout`, `bandwidth` (no x_bar).
- Access predictions ONLY via `np.asarray(result["predicted"])` — the raw value is a Python list-of-lists, calling `.shape` on it raises AttributeError (RESEARCH pitfall 1). Wrap EVERY `["predicted"]` access this way.
- ISE evaluation: `np.trapezoid((pred - resp_test)**2, t_grid, axis=1).mean()` for both global and local. Report both (measured: global ISE ~0.00162, local ISE ~0.00140 — local wins for this spatially heterogeneous data; state the numbers come out of the fence, do not hard-code claims that could drift).
- For the "predicted densities by latitude" figure, call `frechet_global_reg` a second time with `xout_ref = np.array([[45.0],[55.0],[65.0]])` to get predicted densities at three reference latitudes; overlay them on the barycenter.
