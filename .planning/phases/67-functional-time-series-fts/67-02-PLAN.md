<objective>
EXPANSION (FTS-01 forecasting + FTS-03 fPLSR): build the forecasting family out from the
67-01 tracer skeleton — `ftsm_forecast`, `ftsm_forecast_multistep`, `ftsm_update`, and `fplsr`.

Purpose: `ftsm_forecast` / `ftsm_forecast_multistep` / `ftsm_update` take `&FtsmResult` (a Rust
struct) upstream, which Python cannot pass. This plan implements the COMBINED-FUNCTION pattern from
67-RESEARCH.md §6: the Python-facing binding accepts raw data + params, fits `ftsm` internally, then
calls the downstream function. `fplsr` is a standalone fit like `ftsm`.

Output: Four new `#[pyfunction]`s appended to `src/fts_mod.rs` and registered; forecasting-family
tests appended to `tests/test_fts.py`. After this plan a user can produce single- and multi-step
functional forecasts and an fPLSR one-step forecast.
</objective>
