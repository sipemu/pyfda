# Plan 67-05 (gap closure): Refactor FND-02 guard to an invariant check

## Context

Phase 67 verification found the full suite red on exactly one test:
`tests/sklearn/test_foundation.py::test_fdars_init_unchanged` (FND-02). The guard
byte-freezes `python/fdars/__init__.py` against the pre-Phase-55 commit
`bf1a60638c`, so the legitimate, necessary addition of `"fts"` to `_submodule_names`
(the only mechanism that makes `import fdars.fts` work) trips it. The guard will trip
identically for every subsequent binding phase (68–71).

**User decision (grey-area acceptance):** refactor the guard to assert the INVARIANT it
actually protects, not a frozen git-diff. The sklearn-safety invariant (`import fdars`
does not import sklearn) is already independently covered by FND-01
(`test_fdars_imports_without_sklearn`), so FND-02 should protect the *foundation
registration contract*: no historically-required submodule may be dropped or fail to
register, while additive new submodules are allowed.

## Task 1 — Rewrite test_fdars_init_unchanged as an invariant check

</read_first>

<action>
Replace the body of `test_fdars_init_unchanged` (keep the name so traceability/FND-02
mapping is preserved; update the docstring to describe the invariant). The new test MUST:

1. Recover the Phase-55 baseline submodule set from the base commit at test time:
   `git show bf1a60638c0330c3909721dd900e704deeb82e8b:python/fdars/__init__.py`, parse
   its `_submodule_names` collection. Keep the existing `git cat-file -e` base-present
   guard + its actionable shallow-clone message (fetch-depth: 0) — that harness check stays.
2. Import the live `fdars` package and read the current `_submodule_names`.
3. Assert the Phase-55 baseline set is a SUBSET of the current set — i.e. no core
   submodule was removed/renamed. (New additions like `fts` are allowed; removals fail.)
4. Assert the registration mechanism is intact: for every name in the current
   `_submodule_names`, `import fdars.<name>` succeeds AND `getattr(fdars, name)` is the
   same module object (the dynamic sys.modules injection still works).
5. Do NOT assert byte-equality of __init__.py against any commit.

Update the FND-02 comment/docstring block to state the new invariant. Do not weaken
FND-01 (leave test_fdars_imports_without_sklearn untouched).
</action>
