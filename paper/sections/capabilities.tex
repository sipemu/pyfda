\section{Capability Tour}
\label{sec:capabilities}

\texttt{fdars} exposes \npubliccallables{} public callables across
\nsubmodules{} analysis submodules, covering all fourteen capability areas of
Table~\ref{tab:comparison}.
The \ncoverage{} callables backed by at least one curated peer-reviewed
reference are tracked in the machine-readable scientific-provenance layer
(Section~\ref{sec:advisor}).

Each method family in \texttt{fdars} follows the same boundary convention
described in Section~\ref{sec:design}: the user constructs or passes an
\texttt{Fdata} object (or a NumPy array directly for lower-level calls), which
the PyO3 binding converts to an \texttt{FdMatrix}, forwards to
\texttt{fdars-core}, and converts back to a NumPy result.  High-level
\texttt{Fdata} methods wrap this boundary transparently.  The scikit-learn
estimator layer (Section~\ref{subsec:sklearn}) exposes the same methods as
\texttt{fit}/\texttt{transform}/\texttt{predict} estimators for pipeline
composition.

The following minimal, executable snippets walk one representative per method
family; each is sourced from a script that runs against the live \texttt{fdars}
API and has its output deterministically captured (see
\texttt{paper/code/gen\_snippets.py}).  The snippets serve as both
documentation and regression tests: the CI drift gate (\texttt{make
paper-check}) verifies that regenerating them produces no diff against the
committed sources.

\subsection{Basis Representation and Smoothing}

fdars provides B-spline and Fourier basis expansions for functional data via
\texttt{fdars.basis}.
\texttt{fdata\_to\_basis\_1d} returns a \texttt{(coefficients, n\_basis)} tuple,
while \texttt{smooth\_basis\_gcv} selects the smoothing penalty via
generalised cross-validation and returns a dict including the fitted
curves, AIC, BIC, and effective degrees of freedom:

\input{snippets/basis}

\texttt{fdata\_to\_basis\_1d} projects each curve onto a fixed-size basis and
returns the coefficient matrix alongside the basis count, whereas
\texttt{smooth\_basis\_gcv} additionally \emph{chooses} the smoothing penalty by
minimising the generalised cross-validation score, trading data fidelity against
roughness.  Figure~\ref{fig:tour-basis} overlays five raw growth curves with
their B-spline reconstructions under the GCV-selected penalty: the fitted
curves capture the overall growth trajectory, but with only eight basis
functions they partly smooth over the pubertal spurt (residuals of up to about
3.5\,cm).  The basis dimension bounds how much curvature the GCV-chosen penalty
can retain, so it should be chosen generously when sharp features matter.  The
returned AIC/BIC and
effective degrees of freedom quantify this fit--complexity balance for model
comparison.

\subsection{Depth and Outlier Detection}

Functional depth ranks observations by centrality relative to the full
sample~\citep{fraiman_muniz_2001}.
fdars offers Fraiman--Muniz, band, modal, random-projection, and random Tukey
depths via the \texttt{Fdata.depth()} method, and modified band depth
\citep{lopez_pintado_romo_2009} via \texttt{depth.modified\_band\_1d}.
The \texttt{fdars.outliers} submodule adds shape-, magnitude-, and
amplitude-based outlier detection with a Fast-MUOD-style
detector~\citep{ojo_fast_muod_2022} derived from MUOD~\citep{azcorra_muod_2018}.
It scores each curve by regressing it on a single reference curve; fdars uses
the pointwise mean as that reference, whereas Fast-MUOD as published uses the
pointwise or $L^1$ median:

\input{snippets/depth}

Depth assigns each curve a centrality score relative to the whole sample; the
curve of maximum depth is the functional median.  MUOD complements this by
decomposing atypicality into three indices---shape, magnitude, and
amplitude---so that a curve unusual in \emph{form} is flagged separately from one
merely shifted in \emph{level}; each index is flagged at its upper boxplot (IQR)
fence.  Figure~\ref{fig:tour-depth} shades each growth
curve by its Fraiman--Muniz depth (deeper curves drawn more opaque), highlights
the functional median, and marks the curves flagged by the MUOD detector in red.  Read honestly,
depth is a sample-relative ordering and the outlier flags are cutoff-dependent
\emph{candidates} for inspection rather than definitive verdicts.

\begin{figure}[H]
  \centering
  \includegraphics[width=\linewidth]{figures/tour_depth}
  \caption{Growth curves shaded by Fraiman--Muniz depth (deeper curves more
  opaque).  The deepest curve (orange) is the functional median; curves flagged
  by the MUOD detector as shape, magnitude, or amplitude outliers are drawn in red.}
  \label{fig:tour-depth}
\end{figure}

\subsection{Functional PCA and Sparse/Irregular FPCA}
\label{sec:fpca-snippet}

Dense FPCA is available via \texttt{Fdata.to\_pc()}, which returns scores,
rotation, singular values, and centred data.
For sparse or irregularly observed longitudinal data fdars provides PACE
(principal analysis by conditional expectation) through
\texttt{fdars.pace\_fpca.irreg\_fdata\_from\_lists} (the \texttt{PyIrregFdata}
container) and \texttt{fdars.pace\_fpca.pace\_fpca}~\citep{yao_muller_wang_2005}.
Of the Python peers in Table~\ref{tab:comparison}, scikit-fda supports FPCA
for densely observed curves only, while FDApy also offers PACE scoring for
irregularly sampled curves:

\input{snippets/fpca}

The dense path returns scores, the eigenfunction \texttt{rotation} matrix, and
singular values.  The PACE path returns the analogous quantities (mean,
eigenfunctions, eigenvalues, conditional-expectation scores and fitted
trajectories with pointwise bands) for curves observed at subject-specific,
irregularly spaced times.  The snippet illustrates it by artificially
sparsifying the growth data to 8 randomly chosen ages (of 31) per child and
fitting PACE on the age domain: its scores correlate with the dense-data scores
at 0.98 (PC1) and 0.89 (PC2), and its reconstructed trajectories stay within
about 2.7\,cm (RMSE) of the full observations, although each child contributes
only a quarter of the measurements.  The measurement-error variance
\texttt{sigma2} is supplied by the user rather than estimated.  The most useful way to read an
FPCA fit is through its \emph{modes of variation}: the mean curve perturbed by
$\pm 2$ standard deviations along each eigenfunction.
Figure~\ref{fig:tour-fpca} shows the first two for the growth data---the
dominant component is an overall size/level mode, while the second is a timing
contrast that crosses near mid-adolescence, corresponding to \emph{when} the
pubertal growth spurt occurs.  The percentage in each panel title is that
component's share of the \emph{total} variance of the sample, computed live.

  \centering
  \includegraphics[width=\linewidth]{figures/tour_fpca}
  \caption{First two FPCA modes of variation: the mean growth curve (grey)
  perturbed by $\pm 2$ standard deviations along each principal eigenfunction.
  PC1 is an overall-size mode; PC2 is a growth-timing contrast.  Percentages

\subsection{Clustering}

Functional $k$-means~\citep{tarpey_kinateder_2003} partitions observations by
minimising within-cluster $L^2$ distance in the curve space.
\texttt{fdars.clustering.kmeans\_fd} accepts a fixed random seed for
deterministic results and returns cluster assignments, centroids,
total within-cluster sum of squares, and a convergence flag:

\input{snippets/clustering}

Each iteration assigns every curve to its nearest centroid in $L^2$ and
recomputes centroids as within-cluster mean curves, until the assignment
stabilises.  Figure~\ref{fig:tour-clustering} colours the growth curves by their
cluster label and overlays the three centroids: the partition separates
primarily by overall growth level and attained final height.  As with any
$k$-means, the number of clusters $k$ is supplied by the user and the result is
a descriptive summary of the sample's dominant variation---not evidence of
discrete underlying subpopulations.  The fixed \texttt{seed} makes the
initialisation, and hence the reported partition, reproducible.

\subsection{Classification}

fdars provides functional linear discriminant analysis, functional
$k$-nearest neighbours, depth-based DD-classifiers, and elastic-distance
classifiers through \texttt{fdars.classification}.
The FPCA-$k$NN classifier (\texttt{fclassif\_knn}) projects observations onto
the leading principal components and applies $k$-NN in the score space:

\input{snippets/classification}

Projecting onto a handful of principal components before applying $k$-NN keeps
the classifier robust to the high dimensionality of raw curves while retaining
the between-class signal.  Figure~\ref{fig:tour-classification} shows why this
works, and where it struggles, on the phoneme data: the class-mean
log-periodogram spectra of \textit{sh}, \textit{iy} and \textit{dcl} are
distinct from each other and from the two back vowels, whereas \textit{aa} and
\textit{ao} nearly overlap.  A low-dimensional FPCA projection therefore
separates most classes well, and \textit{aa} versus \textit{ao} is the main
source of error.  The snippet reports leave-one-out $k$NN accuracy on the first
100 curves (with the unsupervised FPCA projection fitted on all 100); Case Study~1
(Section~\ref{subsec:cs1-phoneme}) evaluates a closely related pipeline---FPCA
followed by linear discriminant analysis---under full cross-validation.

\subsection{Regression}

\texttt{fdars.regression} covers scalar-on-function (SoF) regression via
functional principal component regression (\texttt{fregre\_lm}), functional
partial least squares (\texttt{fregre\_pls})~\citep{reiss_ogden_2007}, and
robust variants, as well as function-on-function (FoF) regression via
\texttt{fof\_regression}~\citep{yao_muller_wang_2005b}.
The snippet demonstrates SoF regression on the Tecator near-infrared spectra
dataset, predicting fat content from 100-channel absorbance curves:

\input{snippets/regression}

Following standard near-infrared practice~\citep{rinnan_2009}, the snippet first converts the raw
absorbance curves to \emph{second-derivative} spectra---smoothing with a
B-spline basis and differentiating twice---which removes additive baseline offsets and linear baseline trends
(including the additive part of light-scatter effects) and sharpens the fat
absorption bands.
\texttt{fregre\_lm} then projects these curves onto their leading FPCA
components, fits an ordinary linear model in that score space, and returns the
fitted values, residuals, the reconstructed coefficient function $\beta(t)$, and
the coefficient of determination.  Figure~\ref{fig:tour-regression} plots fitted
against observed fat content: points cluster tightly along the identity line.
The $R^2$ shown in the figure is computed live from the fit.  With fifteen
components the raw spectra already fit well, so the preprocessing adds a small
but consistent gain (Case Study~\ref{subsec:cs2-tecator} quantifies it under
cross-validation).  PLS and
robust variants (for collinear or contaminated predictors) and
function-on-function regression share the same call convention.

\begin{figure}[H]
  \centering
  \includegraphics[width=\linewidth]{figures/tour_regression}

  second-derivative absorbance spectra: fitted vs observed values with the live
  $R^2$.  The dashed line marks a perfect fit.}

\end{figure}

\subsection{Functional Time Series}

The \texttt{fdars.fts} submodule implements functional time-series models
(FTSM) for data whose observed unit is a curve indexed by time---for example
one diurnal air-pollution profile per day.
\texttt{ftsm\_forecast} takes the raw data matrix and grid directly and
returns multi-step-ahead curve forecasts:

\input{snippets/fts}

FTSM decomposes the observed curve sequence into functional principal
components, fits an independent univariate autoregressive model to each score
series (Yule--Walker estimation, order chosen by AIC), and reconstructs the next
$h$ curves from the forecast scores.
Figure~\ref{fig:tour-fts} shows a genuine example: the Graz PM10
dataset~\citep{aue_norinho_hormann_2015} records 48 half-hourly PM10
concentrations per day over 182 consecutive days, so the curves form a real
temporal sequence and forecasting the next day's diurnal profile is a
substantive task.  The three forecast curves---back-transformed from the
variance-stabilising square-root scale used for these data by
\citet{aue_norinho_hormann_2015}---sit within the envelope of observed
days and preserve the characteristic diurnal shape.  Because the reconstruction
is low-rank, the forecasts capture the leading modes of variation rather than
fine half-hour-to-half-hour fluctuations.  Case Study~\ref{subsec:cs3-fts} validates
such forecasts over 30 rolling forecast origins against simple baselines.

\begin{figure}[H]
  \centering
  \includegraphics[width=\linewidth]{figures/tour_fts}
  \caption{FTSM forecast of the next three daily PM10 curves (bold) over the
  182 observed daily curves (grey) from the Graz dataset.  Each curve is one
  day's diurnal PM10 profile; the next-day forecasts are validated against
  held-out days in Case Study~\ref{subsec:cs3-fts}.}
  \label{fig:tour-fts}
\end{figure}

\input{snippets/spm}

\subsection{Conformal and Tolerance Bands}

\texttt{fdars.tolerance} constructs tolerance bands for functional data by a
parametric bootstrap from an FPCA model.
\texttt{fpca\_tolerance\_band} returns upper/lower band curves, a centre curve,
and the half-width vector; a fixed \texttt{seed} argument makes the bootstrap
simulation reproducible:

\input{snippets/tolerance}

The band is centred on the pointwise sample mean, and its half-width is a
constant multiple of the pointwise sample standard deviation.  The multiple is
calibrated by a parametric bootstrap: Gaussian FPC scores are simulated from the
fitted FPCA model, and the multiple is chosen so that, with probability 0.95, an
entire simulated sample of $n$ curves lies inside the band over the whole grid.
This makes it a conservative \emph{simultaneous} band rather than one that
contains 95\% of individual curves.  Figure~\ref{fig:tour-tolerance} draws the
band over the growth sample: all 93 curves fall inside it, and apart from a slight
narrowing before age~2 the band widens with age, following the growing between-subject spread in height,
which is largest at the end of the observation period (age~18).  The coverage
is a simulation estimate under the Gaussian FPCA model rather than an exact
finite-sample guarantee, and the fixed \texttt{seed} pins the reported band.

\begin{figure}[H]
  \centering
  \includegraphics[width=\linewidth]{figures/tour_tolerance}
  \caption{95\% simultaneous tolerance band from an FPCA parametric bootstrap
  (shaded) with its centre curve, drawn over the growth sample.  The band widens where
  between-subject variability grows.}
  \label{fig:tour-tolerance}
\end{figure}

\subsection{Metrics, Density, and Fr\'echet Analysis}

\texttt{fdars.metric} provides $L^p$ pairwise distance matrices
(\texttt{lp\_self\_1d}) and dynamic time warping (\texttt{dtw\_self\_1d}) for
functional observations.
Beyond pairwise distances, fdars also provides density-FDA methods (LQD FPCA
and Wasserstein barycenters) in \texttt{fdars.density\_fda}, and Fr\'echet
means and regression~\citep{petersen_muller_2019} and Fr\'echet
ANOVA~\citep{dubey_muller_2019} for object-valued data in
\texttt{fdars.frechet}; see
Table~\ref{tab:comparison} for the full peer comparison.
The snippet illustrates the metric family representative:

\input{snippets/metric}

\texttt{lp\_self\_1d} integrates the pointwise $L^p$ difference between every
pair of curves, while \texttt{dtw\_self\_1d} instead allows elastic time-warping
before measuring distance.  Figure~\ref{fig:tour-metric} renders the $L^2$
distance matrix as a heatmap: the dark diagonal is each curve's zero
self-distance, and the off-diagonal block structure exposes groups of mutually

downstream methods---clustering, $k$-NN classification, and multidimensional
scaling---so the metric family underpins much of the rest of the tour.

\subsection{Elastic Alignment}

\texttt{fdars.alignment} implements elastic registration under the square-root
slope function (SRSF) framework~\citep{srivastava_et_al_2011}.
\texttt{karcher\_mean} estimates the Karcher mean curve by iteratively
aligning observations and re-estimating the mean; the returned dict includes
the aligned data matrix, phase-warping functions ($\gamma$), the iteration
count, and a convergence flag (here reached after 121 of at most 200 iterations):

\input{snippets/alignment}

Elastic registration separates two kinds of variation that ordinary averaging
conflates: \emph{amplitude} (how large a feature is) and \emph{phase} (when it
occurs).  The classic illustration is the Berkeley growth study: each girl's
growth-\emph{velocity} curve---the derivative of her smoothed height curve---has
a pubertal growth spurt, but the spurt occurs at a different age for each child.
Figure~\ref{fig:tour-alignment} shows the consequence.  Before registration the
spurt peaks are spread across ages, so the cross-sectional mean (red, left)
smears them into a low, rounded bump; after \texttt{karcher\_mean} registration
the curves tighten and the Karcher mean (red, right) recovers a sharp spurt at
its true amplitude.  The returned warping functions $\gamma$ record exactly how
each curve's age axis was deformed---a first-class output describing the phase
variation that was removed, not a nuisance by-product.

\begin{figure}[H]
  \centering
  \includegraphics[width=\linewidth]{figures/tour_alignment}
  \caption{Elastic SRSF registration of the growth-velocity curves of 20
  Berkeley girls (ages 5--18; velocities from a B-spline smooth of all 93
  children), before (left) and after (right) \texttt{karcher\_mean}
  alignment.  Registering the pubertal-spurt peak tightens the sample; the
  Karcher mean (red, right) recovers a sharp spurt that the naive
  cross-sectional mean (red, left) smears out.}
  \label{fig:tour-alignment}
\end{figure}

Because the warping functions are a first-class output, they can be analysed in
their own right.  Registering all Berkeley children---boys and girls---to a
common growth-velocity template yields one $\gamma$ per child, and colouring
them by sex exposes a genuine biological contrast
(Figure~\ref{fig:tour-warping}).  The girls' warping functions lie
systematically below the boys': to reach the shared template landmarks---above
all the pubertal spurt---a girl's age axis is mapped to \emph{earlier} ages than
a boy's.  This is the well-documented earlier maturation of girls (peak height
velocity roughly two years sooner), isolated here as pure \emph{phase}
variation---a timing difference the warping functions make explicit and
quantifiable, separate from any difference in spurt amplitude.  The identity
diagonal marks a child who needs no warping (developmental clock exactly on the
template); deviations below it mark earlier development, above it later.
For all 93 children the Karcher iteration is capped at 50 steps and the flag
reports \texttt{converged=False}; the sex contrast is already stable at that
point (the mean boys--girls gap between the warping functions is 1.53 years
after 50 iterations and 1.63 after 300).

\begin{figure}[H]
  \centering
  \includegraphics[width=\linewidth]{figures/tour_warping}
  \caption{SRSF warping functions $\gamma$ from registering all Berkeley
  children's growth-velocity curves to a common Karcher template, coloured by
  sex (thin curves: individuals; bold: per-sex mean).  Girls' warping functions
  lie below boys', mapping the shared spurt landmark to earlier ages---the
  ${\sim}2$-year-earlier maturation of girls as phase variation.  The dashed
  diagonal is the no-warp identity.}
  \label{fig:tour-warping}
\end{figure}

\subsection{Grounded AI Advisor (LLM-Free Diagnostics)}

\texttt{fdars.advisor.build\_diagnostics} computes method-specific structured
diagnostics from the result dicts of sixteen supported method families
(alignment, FPCA, smoothing, clustering, depth, outliers, classification,
regression, monitoring, and others) in a fully offline, deterministic
manner---no LLM provider is required.
The LLM-assisted \texttt{advise()} function takes these diagnostics and a
user-specified task description and queries a configured language model to
generate grounded parameter recommendations; it is described further in
Section~\ref{sec:advisor}.
The snippet demonstrates the offline diagnostic step for FPCA:

\input{snippets/advisor_diag}

The diagnostic reduces a full result dict to the small set of scalars a
practitioner would actually inspect---here, the per-component and cumulative
share of the \emph{total} variance captured by the retained components.
Figure~\ref{fig:tour-advisor} plots exactly these quantities as a scree chart:
the first component alone captures 81\% of the total variance, and the three
retained components together 97.5\%, so the remaining 2.5\% is what a
larger \texttt{n\_comp} could still add.  Because every number is computed from
the data rather than generated by a language model, the resulting guidance is
\emph{grounded}: the optional \texttt{advise()} step passes these diagnostics to
an LLM only to phrase and contextualise a recommendation the numbers already
support (Section~\ref{sec:advisor}).

Estimators compose with the standard \texttt{Pipeline} API, enabling

\input{snippets/sklearn}
